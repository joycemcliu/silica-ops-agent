# Diagnosis debrief

After each diagnosis, review the process to help improve the toolkit and knowledge used in future diagnoses.

- use i-have-adhd skill for writing
- Record what helped, what slowed progress, and any wrong assumptions or missing information.
- Suggest specific toolkit improvements based on problems encountered.
- Capture reusable knowledge about the Silica platform and how to diagnose it. Include evidence and distinguish confirmed facts from inferences.
- Keep it short and avoid repeating the incident report.
- Empty sections are fine. Write none instead of padding.
- Use [the template](docs/_TEMPLATE.md). Save in `docs/` as `<date>-<store>-<slug>.md`, using the incident's slug when available, and link the incident report.
