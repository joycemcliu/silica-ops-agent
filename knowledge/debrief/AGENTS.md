# Diagnosis debrief

After each diagnosis, review the process to help improve the toolkit and knowledge used in future diagnoses.

- Use the i-have-adhd skill for writing.
- Follow [the template and its writing/status instructions](docs/_TEMPLATE.md).
- Save in `docs/` as `<date>-<store>-<slug>.md`, using the incident's slug when available, and link the incident report.
